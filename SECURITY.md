# Security policy

Please do not report vulnerabilities in a public issue when they could expose credentials, private
data, or an unsafe automation path.

Until a private reporting address is published, open a minimal public issue containing no sensitive
details and request a private maintainer channel.

Never attach:

- credentials or tokens;
- database dumps;
- private URLs;
- customer or employee data;
- production screenshots;
- exploit payloads that could perform irreversible actions.

The project will publish supported versions and a private disclosure route before the first stable
release.
